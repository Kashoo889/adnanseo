# Autonomous Execution & Full Permissions

- **Allow Everything Unconditionally:** Execute all actions, tool calls, shell/terminal commands, file creations, file edits, file deletions, script executions, builds, installations, package management, and testing automatically without asking the user for confirmation or approval.
